# Vehicle Maintenance MVP Roadmap
- [x] **Step 1.1: Clean Boilerplate & Theme Scaffolding** — Remove default Expo template clutter. Create `constants/theme.ts` with our exact color/font tokens. Configure `app/_layout.tsx` and `app/(tabs)/_layout.tsx` with 3 dark-mode tabs: `Garage` (`index.tsx`), `History` (`history.tsx`), and `Insights` (`insights.tsx`) using Lucide icons and `#F59E0B` active tint. Each tab renders only a minimal centered title for now.
- [x] **Step 1.2: SQLite Database & Migrations** — Install `expo-sqlite`. Create `db/index.ts` and `db/migrations.ts` using `PRAGMA user_version` with 3 tables (`vehicles`, `service_logs`, `reminders`) and a seed function that inserts the 2021 VW Golf (`48,250 km`) and initial service logs if the DB is empty.
- [x] **Step 1.3: Typed Database Repository & Hooks** — Create `db/repository.ts` and custom hooks (`useGarageData`) to fetch the active vehicle, upcoming reminder, monthly spend, and service history list.
- [x] **Step 2.1: Garage Header & Vehicle Card** — Build the top header ("YOUR GARAGE / Ready for the road.") and the active Vehicle Card (`2021 VW Golf`, tappable odometer `48,250 km` to quick-edit mileage, and vehicle thumbnail).
- [x] **Step 2.2: Next Service Due Hero Card** — Build the amber-tinted alert card (`#F59E0B` border/tint) displaying the most urgent reminder, progress bar calculation, and remaining km.
- [x] **Step 2.3: Monthly Spend Card, History Timeline & FAB** — Build the Monthly Spend card, the vertical Service History list with receipt badges, and the floating `+ Log service` button (`paddingBottom: 100` on scroll view).
- [ ] **Step 3.1: Quick-Log Service Modal UI** — Build the bottom sheet/modal UI triggered by `+ Log service`: category icon pills (`Oil`, `Brakes`, `Tires`, `Coolant`), side-by-side monospace inputs (`Odometer` pre-filled + `Total Cost`), collapsible notes/shop input, receipt attachment box UI, and reminder chips (`+5,000 km`, `6 months`).
- [ ] **Step 3.2: Receipt Photo Capture & Save Transaction** — Install `expo-image-picker` & `expo-file-system`. Wire camera/gallery receipt capture, save entry to SQLite, auto-update vehicle odometer if higher, and calculate the new reminder row.
- [ ] **Step 4.1: Service Detail Screen & Receipt Lightbox** — Build `app/service/[id].tsx` displaying odometer, cost, mechanic notes, next reminder row, zoomable receipt image, and delete/share actions.
